# Tanogaido — Explore Authentic Japan

Landing page interaktif modern dengan animasi scroll-driven canvas 300 frame Gunung Fuji, navigasi responsif dinamis, dan etalase layanan wisata Jepang.

## Fitur Unggulan
- **Scroll-Driven Canvas Animation**: 300 sequential HD frame dengan interpolasi halus (*lerp*) dan background freeze saat menjelajahi layanan.
- **Dynamic Shrinking Header**: Navbar menyusut dan otomatis memusat ke tengah saat scroll.
- **Aggressive Hero Exit**: Elemen hero bertransisi ke atas secara cepat untuk memaksimalkan ruang layar.
- **Etalase 5 Layanan Wisata Jepang**:
  1. **Virtual Tour Guide Online** (Pendampingan WhatsApp 24/7)
  2. **Private Tour & Itinerary** (Guide bilingual lokal berlisensi)
  3. **Sewa Mobil & Private Driver** (Armada Alphard, HiAce, bus)
  4. **JR Pass & Tiket Shinkansen** (Tiket resmi kereta cepat)
  5. **Visa Jepang & Pocket WiFi 4G** (E-Visa cepat & internet unlimited)
- **WhatsApp Integration**: Konsultasi langsung ke WhatsApp resmi Tanogaido.

## Menjalankan Secara Lokal
Jalankan server Node.js:
```bash
node serve.mjs
```
Buka browser di `http://localhost:3000/`.
